NPPES Data-Quality Profiling — US Healthcare Provider Registry

Python · pandas · Jupyter · NPPES NPI Registry API v2.1

In my current role I verify healthcare provider records against the NPPES registry — the national directory of US healthcare providers — so I know first-hand how messy its self-reported data gets. For this project I pulled a 600-record Texas sample from the live API and profiled six classes of data-quality issues that anyone using the registry for provider matching or claims work would inherit.

Africa's Aviation Gap — Underserved Markets and Who's Positioned to Serve Them In Progress

Python · pandas · Jupyter · World Bank Open Data (2015–latest)

Africa holds ~18% of the world's population but only a small fraction of its air traffic. Using current World Bank indicators — air passengers carried, population, GDP per capita, and GDP growth — this project identifies which African markets are most underserved relative to their size and economy, measures how fully each market has recovered since COVID, and maps which international carriers are positioned to fill the gaps.

Gateway & Feeder — Who Really Controls African Skies Planned

Follow-up study · curated route dataset

International carriers reach only a handful of African gateway hubs — the connecting traffic beyond them belongs to African airlines. This follow-up maps where intercontinental flights land and which regional carriers cover the last mile, revealing the structure of connectivity across the continent.
